# MTANI TECH multi-page marketplace

## Pages and features
- Home page with category navigation and featured product cards.
- Separate Computers, Phones, Coding & Electronics, Accessories, and Software category pages.
- Product details page, enquiry cart, developer downloads page, seller information, and contact page.
- Client-side search, sorting, saved items, persistent enquiry cart, WhatsApp enquiry links, responsive navigation and offline page caching.

The site is hosted on GitHub Pages, so the interactive features are browser-side. Product ideas and price bands are examples only until verified seller inventory is connected. They are not confirmed listings or guaranteed Tanzanian market prices.

## Payments and sales
This website does **not** currently collect online payments or release paid downloads. It routes purchase enquiries to WhatsApp **+255 639 784 923**. To accept money, you must first onboard a merchant account with a payment provider available in Tanzania and add a trusted backend/server to create transactions, validate product prices and inventory, verify payment webhooks, handle refunds and only then deliver digital goods. Never put merchant secret keys or private paid files in public GitHub Pages code. Do not collect card details on this website. Confirm provider availability, merchant KYC, fees and settlement terms directly with providers such as [ClickPesa](https://clickpesa.com/), [DPO Pay](https://dpogroup.com/online-payments/tanzania/) or [Pesapal](https://www.pesapal.com/).

## Local setup
No build step is required. GitHub Pages publishes the HTML, CSS and JavaScript when changes land on `main`. Free developer tool links point to publishers' websites (VS Code, Python, Git, Arduino IDE, Node.js, Android Studio, GitHub Desktop, Docker, Blender and Postman); MTANI TECH does not host those binaries.

Product photos are illustrative stock photos. Use seller-owned or permission-cleared photos for actual inventory. Verify seller identity, product authenticity, stock, condition, warranty, final price and delivery before purchase.
